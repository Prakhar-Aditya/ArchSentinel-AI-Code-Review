I worked on developing the Security and Performance Agents for our AI-based code optimization tool. I implemented agents that analyze source code to detect security vulnerabilities such as SQL injection, unsafe input handling, and authentication risks, along with performance issues such as inefficient algorithms, redundant loops, and high time or space complexity. I also improved the agent prompts using few-shot examples, added Zod-based validation to ensure reliable AI-generated responses, created automated integration tests to verify findings and severity levels, and prepared technical documentation explaining the agents, rules, prompt design, and customization process.
